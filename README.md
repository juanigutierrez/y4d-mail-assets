# Y4D Mail Assets

Repositorio público de recursos gráficos para comunicaciones HTML de **Youth for Democracy (Y4D)** y **Kairos Global**.

El repositorio está pensado para funcionar con **GitHub Pages**. Una vez activado Pages, cada imagen cargada obtiene una URL HTTPS pública y estable que puede utilizarse directamente dentro de correos HTML.

## Estructura recomendada

- `brand/y4d/` — logos y recursos permanentes de Youth for Democracy.
- `brand/kairos/` — logos y recursos permanentes de Kairos Global.
- `regions/` — recursos visuales por región de Y4D.
- `partners/` — logos de instituciones aliadas que realmente deban aparecer en comunicaciones.
- `editions/` — recursos específicos de cada edición, organizados por año/provincia.
- `flyers/` — piezas temporales o transversales.
- `general/` — recursos gráficos generales.

La portada `index.html` funciona como biblioteca: encuentra automáticamente las imágenes del repositorio, permite buscarlas, filtrarlas y copiar el enlace público de GitHub Pages.

Leé `GUIA-PASO-A-PASO.md` antes de configurarlo.
